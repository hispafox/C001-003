## Objetivo Didáctico

Demostrar **few-shot**: dar 2 ejemplos de funciones con un PATRÓN específico, y pedir una 3ª que siga ese mismo patrón. Luego comparar el resultado few-shot vs zero-shot para la misma tarea.

**Mensaje clave**: "Cuando necesitas que la IA siga convenciones específicas, dar ejemplos es más efectivo que describir las convenciones."

## Prompt para el Agente de IA

```
Crea un script Python que demuestre la técnica few-shot con funciones
de transformación de datos. El script compara few-shot vs zero-shot.

PARTE 1 — LOS 2 EJEMPLOS (el "few" del few-shot):

Ejemplo A (dado en el prompt):
def transform_users(raw_data: list[dict]) -> list[dict]:
    """Transforma datos crudos de usuarios al formato estándar.
    
    Pipeline: validar → limpiar → normalizar → enriquecer
    """
    results = []
    for item in raw_data:
        # Validar
        if not item.get("name") or not item.get("email"):
            continue
        # Limpiar
        cleaned = {
            "full_name": item["name"].strip().title(),
            "email": item["email"].strip().lower(),
            "age": int(item.get("age", 0)) if str(item.get("age", "")).isdigit() else None,
        }
        # Normalizar
        cleaned["age_group"] = (
            "junior" if cleaned["age"] and cleaned["age"] < 30
            else "senior" if cleaned["age"] and cleaned["age"] >= 30
            else "unknown"
        )
        # Enriquecer
        cleaned["domain"] = cleaned["email"].split("@")[1] if "@" in cleaned["email"] else "invalid"
        cleaned["is_valid"] = "@" in cleaned["email"] and "." in cleaned["domain"]
        results.append(cleaned)
    return results

Ejemplo B (dado en el prompt):
def transform_products(raw_data: list[dict]) -> list[dict]:
    """Transforma datos crudos de productos al formato estándar.
    
    Pipeline: validar → limpiar → normalizar → enriquecer
    """
    results = []
    for item in raw_data:
        if not item.get("name") or not item.get("price"):
            continue
        cleaned = {
            "product_name": item["name"].strip().title(),
            "price": round(float(item.get("price", 0)), 2),
            "currency": item.get("currency", "EUR").upper(),
            "category": item.get("category", "uncategorized").lower(),
        }
        cleaned["price_range"] = (
            "budget" if cleaned["price"] < 10
            else "mid" if cleaned["price"] < 50
            else "premium" if cleaned["price"] < 200
            else "luxury"
        )
        cleaned["price_with_tax"] = round(cleaned["price"] * 1.21, 2)
        cleaned["is_valid"] = cleaned["price"] > 0
        results.append(cleaned)
    return results

PARTE 2 — PROMPT FEW-SHOT:
"Siguiendo EXACTAMENTE el mismo patrón de transform_users y
transform_products (pipeline: validar → limpiar → normalizar →
enriquecer, misma estructura, misma convención de nombres),
crea transform_orders(raw_data) para datos de pedidos."

PARTE 3 — PROMPT ZERO-SHOT (misma tarea, sin ejemplos):
"Crea una función transform_orders que transforme datos crudos de
pedidos. Incluye validación, limpieza, normalización y enriquecimiento."

PARTE 4 — COMPARACIÓN:
Clase FewShotComparator:
- compare(few_shot_fn, zero_shot_fn, test_data) -> dict:
  Ejecuta ambas con los mismos datos y compara:
  - ¿Mismos campos de salida?
  - ¿Mismas convenciones de nombres? (snake_case, etc.)
  - ¿Mismo pipeline (validar→limpiar→normalizar→enriquecer)?
  - ¿Misma estructura de docstring?
  - Puntuación de consistencia con los ejemplos (0-100)

DATOS DE TEST (embebidos):
- 5 pedidos válidos con campos: order_id, customer, items, total, date
- 3 pedidos inválidos (sin customer, sin total, total negativo)

10 TESTS:
1. transform_users funciona con datos válidos
2. transform_users filtra datos sin email
3. transform_products funciona con datos válidos
4. transform_products calcula precio con impuesto
5. transform_orders_fewshot sigue el pipeline validar→limpiar→normalizar→enriquecer
6. transform_orders_fewshot devuelve is_valid en cada registro
7. transform_orders_fewshot filtra datos inválidos
8. Zero-shot también genera función funcional
9. Few-shot produce campos más consistentes con los ejemplos
10. FewShotComparator detecta diferencias entre ambas versiones

Docstrings Google Style, type hints. Solo librería estándar.
```
