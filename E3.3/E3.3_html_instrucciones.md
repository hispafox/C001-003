## Prompt para el Agente de IA

```
Crea un conversor de colores interactivo en un único archivo HTML.

CONVERSIÓN BIDIRECCIONAL entre 3 formatos:
- HEX: #FF5733 (input text con validación)
- RGB: R:255 G:87 B:51 (3 sliders + inputs numéricos)
- HSL: H:11° S:100% L:60% (3 sliders + inputs numéricos)

Al cambiar CUALQUIER valor, los otros 2 formatos se actualizan
automáticamente en tiempo real.

PREVIEW:
- Cuadrado grande (200x200) con el color actual
- Texto de ejemplo sobre el color (blanco y negro) para ver contraste
- Indicador de contraste WCAG (AA/AAA pass/fail para texto blanco y negro)

PALETA:
- Últimos 10 colores usados (en memoria, como chips clickeables)
- 12 colores predefinidos (rojo, naranja, amarillo, verde, cyan,
  azul, púrpura, rosa, blanco, gris, negro, dorado)
- Click en cualquier color de la paleta carga ese color

FUNCIONALIDADES EXTRA:
- Botón "Random" que genera color aleatorio
- Botón "Copiar HEX" que copia al clipboard
- Botón "Complementario" que muestra el color complementario
- Barra de luminosidad: variantes del color actual en 9 tonos
  (de muy oscuro a muy claro)

DISEÑO: tema oscuro, sliders con el color actual como thumb,
preview grande y prominente, responsive. Sin CDN.
```
