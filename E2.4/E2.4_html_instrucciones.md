## Prompt para el Agente de IA

```
Crea un visualizador de algoritmos de ordenación en un único archivo HTML.

4 ALGORITMOS:
1. Bubble Sort
2. Selection Sort
3. Insertion Sort
4. Quick Sort

VISUALIZACIÓN:
- Array de 30-50 barras verticales de alturas aleatorias
- Cada barra es un div con height proporcional al valor
- Colores durante la animación:
  - Azul: sin procesar
  - Rojo: comparando actualmente
  - Verde: en su posición final
  - Amarillo: pivote (Quick Sort)
- Animación paso a paso con velocidad configurable

CONTROLES:
- Selector de algoritmo (4 opciones)
- Slider de velocidad (lento → rápido, 5 niveles)
- Slider de tamaño del array (20-80 barras)
- Botón "Generar nuevo array" (aleatorio)
- Botón "Ordenar" (inicia animación)
- Botón "Pausar / Reanudar"
- Botón "Paso a paso" (un paso cada vez)

ESTADÍSTICAS en tiempo real:
- Comparaciones realizadas
- Intercambios realizados
- Tiempo transcurrido
- Complejidad teórica del algoritmo seleccionado

INFORMACIÓN del algoritmo:
- Panel con nombre, descripción breve, complejidad (mejor, promedio, peor),

- Tema oscuro, barras con gradiente de color según valor

- Los algoritmos deben ser generadores (yield en cada paso) para
```

## Especificación Técnica

### Archivo: `e2_4_sorting_visualizer.html`

### Algoritmos como funciones async:
```javascript
async function bubbleSort(arr) {
    for (var i = 0; i < arr.length; i++) {
        for (var j = 0; j < arr.length - i - 1; j++) {
            stats.comparisons++;
            highlight(j, j+1, "comparing");
            await sleep();
            if (arr[j] > arr[j+1]) {
                swap(arr, j, j+1);
                stats.swaps++;
                await sleep();
            }
        }
        markSorted(arr.length - i - 1);
    }
}
```

### Sleep controlable:
```javascript
var speedMs = 50; // ajustable con slider
function sleep() {
    return new Promise(function(resolve) {
        setTimeout(resolve, speedMs);
    });
}
```

### Pausa:
Variable `paused` que se verifica en cada paso con un while loop + await.

### Info de algoritmos:
