## Objetivo Didáctico

Evaluar dónde la IA acierta y dónde falla al resolver problemas algorítmicos. El alumno pide 3 problemas de dificultad creciente y verifica los resultados con tests exhaustivos.

**Mensaje clave**: "La IA resuelve bien algoritmos clásicos (patrones conocidos), pero puede fallar en razonamiento novedoso o edge cases sutiles."

---

## Prompt para el Agente de IA

```
Implementa 3 problemas algorítmicos en Python, cada uno en su propia
clase, con tests exhaustivos. Todos en un único archivo.

PROBLEMA 1 — Las 8 Reinas (backtracking):
Clase EightQueens:
- solve(n: int = 8) -> list[list[int]]: encuentra TODAS las soluciones
  para colocar N reinas en un tablero NxN sin que se ataquen.
  Cada solución es una lista de N enteros donde el índice es la fila
  y el valor es la columna.
- count_solutions(n: int = 8) -> int: número total de soluciones
- print_board(solution: list[int]) -> str: representación visual
  con ♛ y · del tablero
- is_valid(solution: list[int]) -> bool: verifica si una solución
  es válida (ninguna reina ataca a otra)

PROBLEMA 2 — Evaluador de Expresiones Matemáticas:
Clase ExpressionEvaluator:
- evaluate(expression: str) -> float: evalúa expresiones como
  "3 + 4 * 2 / (1 - 5)"
  Soporta: +, -, *, /, paréntesis, números decimales, negativos
  Implementar con el algoritmo Shunting-Yard de Dijkstra
  (NO usar eval() ni compile())
- tokenize(expression: str) -> list: divide en tokens
- Manejo de errores: división por cero, paréntesis no balanceados,
  expresión vacía, caracteres inválidos

PROBLEMA 3 — Calculadora de Probabilidad Bayesiana:
Clase BayesCalculator:
- calculate(prior: float, likelihood: float,
            evidence: float) -> float:
  Aplica el teorema de Bayes: P(A|B) = P(B|A) * P(A) / P(B)
- calculate_with_complement(prior: float, true_positive: float,
                            false_positive: float) -> float:
  Versión más práctica: calcula P(enfermedad|test+) dados
  prevalencia, sensibilidad y tasa de falsos positivos
- explain(prior, likelihood, evidence) -> str:
  Devuelve explicación paso a paso del cálculo en español

DEMO: para cada problema, mostrar ejemplo visual/explicativo.
- 8 Reinas: imprimir un tablero con solución + total de soluciones
- Expresiones: evaluar 5 expresiones de complejidad creciente
- Bayes: ejemplo médico (test con 99% sensibilidad, enfermedad
  con 1% prevalencia → ¿probabilidad real de estar enfermo?)

12 TESTS:
1. 8 Reinas N=4 tiene exactamente 2 soluciones
2. 8 Reinas N=8 tiene exactamente 92 soluciones
3. 8 Reinas is_valid confirma solución correcta
4. 8 Reinas is_valid rechaza solución inválida
5. Expresión "2 + 3" = 5.0
6. Expresión "3 + 4 * 2 / (1 - 5)" = 1.0
7. Expresión con decimales "3.5 * 2" = 7.0
8. Expresión paréntesis no balanceados → ValueError
9. Bayes básico: prior=0.5, likelihood=0.8, evidence=0.5 → 0.8
10. Bayes médico: prevalencia 1%, sensibilidad 99%, falso+ 5% → ~16.7%
11. Bayes con probabilidades inválidas (>1 o <0) → ValueError
12. Expresión vacía → ValueError

Docstrings Google Style, type hints. Solo librería estándar.
```
