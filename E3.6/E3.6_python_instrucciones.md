---

## Objetivo Didáctico

Integrar TODAS las técnicas del Módulo 3 en un solo proyecto:
- **Elementos del prompt** (E3.1): prompt con contexto, rol, restricciones, ejemplos
- **Zero-shot** (E3.2): parser de logs sin ejemplos de código
- **Few-shot** (E3.3): dar 2 formatos de log y pedir que parsee un 3º
- **Chain of Thought** (E3.4): "piensa en qué patrones buscar antes de implementar"
- **Cadena de prompts** (E3.5): 4 prompts secuenciales (parser → analyzer → alertas → report)

---

## Prompt para el Agente de IA

```
Crea un analizador de logs en Python usando TODAS las técnicas
de ingeniería de prompts aprendidas.

CADENA DE 4 PROMPTS:

PROMPT 1 — LogParser (zero-shot + elementos del prompt):
Contexto: sistema de monitorización de servidores web.
Rol: ingeniero SRE senior.
Clase LogParser:
- parse_line(line: str) -> dict | None
- Parsea formatos: Apache, Nginx, JSON, Syslog
- Devuelve: {timestamp, level, source, message, ip, status_code, extras}
- Manejo de líneas malformadas (devuelve None)

PROMPT 2 — LogAnalyzer (few-shot + CoT):
Piensa paso a paso: ¿qué métricas son útiles para un SRE?
Clase LogAnalyzer:
- add_entries(entries: list[dict])
- count_by_level() -> dict (DEBUG, INFO, WARNING, ERROR, CRITICAL)
- count_by_source() -> dict
- count_by_hour() -> dict (distribución horaria)
- top_ips(n=5) -> list de (ip, count)
- top_errors(n=5) -> list de (message, count)
- error_rate() -> float (porcentaje de ERROR+CRITICAL)

PROMPT 3 — AlertRule (few-shot: dar 2 reglas de ejemplo):
Ejemplo A: "Si error_rate > 10%, alerta CRITICAL"
Ejemplo B: "Si más de 100 errores en 1 hora, alerta WARNING"
Siguiendo ese patrón, crea:
- Clase AlertRule con name, condition_fn, severity
- Clase AlertEngine con add_rule, evaluate(analyzer) -> list[Alert]
- 5 reglas predefinidas

PROMPT 4 — Report (cadena final):
- Clase ReportGenerator
- generate(analyzer, alerts) -> str: informe en texto plano
- Resumen, métricas, alertas, recomendaciones

LOGS DE TEST: 30 líneas embebidas (mix de formatos, niveles, IPs)
incluyendo 5 errores y 2 líneas malformadas.

10 TESTS que verifican toda la cadena.
Docstrings Google Style, type hints. Solo librería estándar.
```
