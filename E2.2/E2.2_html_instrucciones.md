## Objetivo Didáctico

Demostrar que la IA genera apps de transformación de datos interactivas. El conversor trabaja con múltiples categorías y fórmulas de conversión bidireccional en tiempo real.


## Especificación Técnica

### Archivo: `e2_2_unit_converter.html`

### Estructura de datos para conversiones:
Cada categoría tiene un objeto con factores de conversión relativos a
una unidad base (ej: metro para longitud, kg para peso).

```javascript
var CATEGORIES = {
    longitud: {
        icon: "📏",
        base: "metro",
        units: {
            "metro": 1,
            "kilómetro": 1000,
            "centímetro": 0.01,
            "milímetro": 0.001,
            "milla": 1609.344,
            "yarda": 0.9144,
            "pie": 0.3048,
            "pulgada": 0.0254,
            "milla náutica": 1852
        }
    },
    // ...
};
```

Para temperatura: usar funciones especiales (no es multiplicativa).

### Conversión:
```
resultado = valor * (factor_origen / factor_destino)
```
Excepto temperatura que requiere fórmulas específicas.

### Historial:
Array en memoria (no localStorage), máximo 10 entradas, más reciente primero.

## Resultado Esperado

Al abrir en navegador:
- Tabs con 8 categorías con iconos
- Campos "De" y "A" con conversión en tiempo real
- Al escribir "100" en km con destino millas → muestra "62.1371"
- Botón ↔ intercambia unidades instantáneamente
- Fórmula visible: "1 km = 0.6214 mi"
- Tabla de referencia rápida con conversiones comunes
- Historial crece al convertir
