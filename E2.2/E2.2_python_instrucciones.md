## Objetivo Didáctico

Demostrar que los LLMs entienden instrucciones complejas de transformación de datos y generan código que trabaja con múltiples formatos de salida en una sola petición.

---

## Prompt para el Agente de IA

```
Crea un conversor multiformato en Python que transforme datos CSV
en tres formatos de salida distintos. Requisitos:

DATOS DE ENTRADA (CSV embebido como string para demo):
Columnas: nombre, email, departamento, salario, fecha_ingreso
Al menos 12 empleados en 4 departamentos (Ingeniería, Marketing,
Ventas, RRHH) con salarios variados (30000-85000).

CLASE DataConverter:
- __init__(self, csv_data: str): parsea el CSV con el módulo csv
- to_json_grouped(self) -> str: JSON agrupado por departamento
  Estructura: {"departamento": [{"nombre": ..., "email": ..., ...}]}
  Con indentación de 2 espacios
- to_markdown_report(self) -> str: informe Markdown con:
  - Título "# Informe de Empleados"
  - Tabla Markdown con todos los empleados
  - Sección "## Estadísticas por Departamento" con:
    - Número de empleados, salario medio, mín, máx por departamento
  - Sección "## Resumen Global" con total empleados, salario medio global
- to_html_table(self) -> str: HTML completo (<!DOCTYPE html>) con:
  - Tabla estilizada con CSS embebido (alternating rows, header coloreado)
  - Título, fecha de generación
  - Responsive (max-width, overflow-x)
  - Filas coloreadas por departamento (un color por departamento)
- validate(self) -> list[str]: detectar anomalías:
  - Emails sin @
  - Salarios negativos o > 200000
  - Nombres vacíos
  Devuelve lista de strings con los problemas encontrados
- summary(self) -> dict: resumen con total_empleados, departamentos,
  salario_medio, anomalias

DATOS DE PRUEBA CON ANOMALÍAS:
Incluir 2-3 registros intencionalmente anómalos entre los 12:
- Un email sin @ (ej: "juan.garcia.invalid")
- Un salario negativo (ej: -5000)
- Un nombre vacío

CLI con argparse:
- Sin argumentos: demo con datos embebidos + muestra los 3 formatos
  + validación + 10 tests
- Con --input archivo.csv: lee CSV real
- Con --output-dir directorio: guarda los 3 archivos (datos.json,
  informe.md, tabla.html)
- Con --validate: solo muestra anomalías

10 TESTS:
1. Parseo CSV: número correcto de registros
2. JSON agrupado: 4 departamentos
3. JSON parseable: json.loads no falla
4. Markdown contiene tabla (líneas con |)
5. Markdown contiene estadísticas por departamento
6. HTML contiene <table> y <th>
7. HTML es documento completo (<!DOCTYPE html>)
8. Validación detecta email inválido
9. Validación detecta salario negativo
10. Summary tiene las claves correctas

Usa solo librería estándar. Docstrings Google Style, type hints.
```
