## Objetivo Didáctico

Demostrar **Chain of Thought (CoT)**: pedir a la IA que "piense paso a paso" antes de generar código produce soluciones más completas y robustas. Comparamos un prompt directo vs un prompt con CoT para la misma tarea.

**Mensaje clave**: "Pedir a la IA que razone antes de codificar reduce errores en problemas complejos."

---

## Prompt para el Agente de IA

```
Crea un script Python que demuestre Chain of Thought comparando
dos versiones de un detector de ciclos en grafos dirigidos.

VERSIÓN A — PROMPT DIRECTO (sin CoT):
"Detecta ciclos en un grafo dirigido. Devuelve True si hay ciclo."
→ Genera detect_cycle_direct(graph) que solo devuelve bool.

VERSIÓN B — PROMPT CON CHAIN OF THOUGHT:
"Piensa paso a paso antes de implementar:
1. ¿Qué algoritmo es mejor para detectar ciclos? (DFS con colores)
2. ¿Qué estados necesita cada nodo? (WHITE=no visitado, GRAY=en proceso, BLACK=completado)
3. ¿Cuándo hay ciclo? (cuando DFS encuentra un nodo GRAY)
4. ¿Qué edge cases existen? (grafo vacío, nodo aislado, self-loop, múltiples componentes)
5. ¿Qué info adicional sería útil? (los nodos del ciclo, el camino)
Ahora implementa el detector."
→ Genera clase CycleDetector con:
  - detect(graph) -> dict con has_cycle, cycle_nodes, cycle_path, algorithm
  - find_all_cycles(graph) -> list de ciclos
  - topological_sort(graph) -> list | None (None si hay ciclo)
  - visualize(graph) -> str (representación ASCII del grafo)

CLASE Graph:
- add_edge(from_node, to_node)
- add_node(node)
- get_neighbors(node) -> list
- get_all_nodes() -> set
- from_dict(adj_dict) -> Graph (factory method)

GRAFOS DE TEST (5):
1. Sin ciclo: A→B→C→D (lineal)
2. Con ciclo simple: A→B→C→A
3. Self-loop: A→A
4. Múltiples componentes: {A→B→C, D→E→D} (1 componente con ciclo, 1 sin)
5. Grafo complejo: 6+ nodos con ciclo anidado

12 TESTS:
1. Grafo sin ciclo: has_cycle=False (versión directa)
2. Grafo con ciclo: has_cycle=True (versión directa)
3. CoT: grafo sin ciclo, has_cycle=False + cycle_nodes vacío
4. CoT: grafo con ciclo, devuelve los nodos del ciclo
5. CoT: self-loop detectado
6. CoT: múltiples componentes, detecta ciclo en el que lo tiene
7. Topological sort funciona en grafo sin ciclo
8. Topological sort devuelve None en grafo con ciclo
9. Grafo vacío no lanza error
10. Versión directa: solo bool, sin info extra
11. Versión CoT: dict con 4+ campos
12. Visualize genera representación del grafo

Docstrings Google Style, type hints. Solo librería estándar.
```
