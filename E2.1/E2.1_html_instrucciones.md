## Objetivo Didáctico

Demostrar que la IA genera aplicaciones web interactivas complejas. El alumno construye un generador que, dado un esquema JSON, renderiza un formulario HTML completo con validación en tiempo real.

## Especificación Técnica

### Archivo: `e2_1_form_generator.html`

### Tipos de campo soportados:
| type | Renderiza como | Validaciones |
|---|---|---|
| text | `<input type="text">` | required, minLength, maxLength |
| email | `<input type="email">` | required, pattern |
| password | `<input type="password">` | required, minLength |
| number | `<input type="number">` | required, min, max |
| tel | `<input type="tel">` | required, pattern |
| url | `<input type="url">` | required |
| date | `<input type="date">` | required, min, max |
| textarea | `<textarea>` | required, maxLength |
| select | `<select>` con options | required |
| checkbox | `<input type="checkbox">` | — |
| radio | grupo de `<input type="radio">` | required |
| range | `<input type="range">` con valor | min, max, step |
| color | `<input type="color">` | — |

### JavaScript core:
- `parseSchema(json)`: parsea JSON, devuelve array de campos o error
- `renderForm(fields)`: genera HTML del formulario dinámicamente
- `validateField(field, value)`: valida un campo, devuelve {valid, message}
- `validateAll()`: valida todos los campos, devuelve datos o errores
- Event listener en textarea del editor: `input` → re-render

### Error handling:
- JSON.parse en try/catch
- Si falla: mostrar línea y carácter del error
- Campos con type no soportado: mostrar warning

## Resultado Esperado

Al abrir en navegador:
- Editor JSON a la izquierda con esquema de ejemplo
- Formulario renderizado a la derecha con 8 campos de diferentes tipos
- Validación en tiempo real (borde rojo/verde, mensajes de error)
- Botón submit muestra datos en JSON si todo es válido
- Modificar el JSON re-renderiza el formulario instantáneamente
- Error de sintaxis JSON muestra mensaje claro
