## Contexto

Curso "IA Generativa para el Desarrollo: Herramientas". Agentes de IA generan el código completo.

|---|---|

| Módulo | 3.2.1 — Zero-shot learning |
| Dependencias | Archivo único .html, sin CDN |

---

## Prompt para el Agente de IA

```
Crea un cronómetro multi-timer en un único archivo HTML.
Un solo prompt sin código de ejemplo (zero-shot).

FUNCIONALIDAD:
- Botón "Nuevo Timer" que crea un temporizador independiente
- Cada timer tiene: nombre editable, display HH:MM:SS.ms,
  botones Start/Pause/Reset/Eliminar
- Hasta 8 timers simultáneos funcionando en paralelo
- Modo cronómetro (cuenta hacia arriba desde 0)
- Modo temporizador (cuenta atrás desde tiempo configurado):
  - Input para minutos y segundos
  - Alerta visual (parpadeo rojo) + sonido (beep con AudioContext)
    cuando llega a 0
- Lap/vuelta: botón que registra el tiempo actual como "lap"
  con lista de laps debajo del timer
- Timer global: muestra la suma de todos los timers activos

PRESETS: botones rápidos para temporizadores comunes:
  "Pomodoro 25min", "Descanso 5min", "Reunión 30min", "1 hora"

DISEÑO: tema oscuro, display grande tipo reloj digital (monospace),
cada timer en una tarjeta con borde de color diferente, responsive.
Grid de 2 columnas (1 en móvil).

TODO en un único archivo .html, cero dependencias.
AudioContext para el beep (no archivo de audio externo).
```

---

## Resultado Esperado

Al abrir en navegador:
- Botón "Nuevo Timer" + 4 presets
- Cada timer: nombre editable, display grande, Start/Pause/Reset/Lap/X
- Varios timers corriendo simultáneamente
- Modo temporizador con alerta al llegar a 0
- Timer global con suma de todos
