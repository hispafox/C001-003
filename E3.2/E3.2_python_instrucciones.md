## Objetivo Didáctico

Demostrar **zero-shot**: un único prompt sin ejemplos previos produce código funcional. El prompt es detallado pero NO incluye código de ejemplo — la IA genera todo de cero.

**Mensaje clave**: "Zero-shot funciona bien para tareas conocidas si el prompt es suficientemente descriptivo."

---

## Prompt para el Agente de IA

```
Crea un decorador Python llamado @retry que reintente funciones que
fallan con espera exponencial. Un solo prompt, sin código de ejemplo.

COMPORTAMIENTO:
- @retry(max_retries=3, base_delay=1.0, max_delay=60.0,
         exceptions=(Exception,), jitter=True)
- Si la función lanza una excepción en exceptions, espera y reintenta
- Espera exponencial: delay = base_delay * 2^intento
- Si jitter=True: añade variación aleatoria ±25% al delay
- Si supera max_delay: usa max_delay
- Si supera max_retries: re-lanza la última excepción
- Preservar firma y docstring con functools.wraps
- Logging de cada reintento: "Retry {n}/{max}: {excepción}. Waiting {delay}s"

CLASE RetryConfig:
- Almacena la configuración del retry
- Método calculate_delay(attempt) -> float

FUNCIÓN retry_with_stats:
- Versión que además registra estadísticas:
  total_calls, total_retries, total_failures, success_rate

DEMO CON 3 FUNCIONES:
1. Función que falla 2 veces y luego tiene éxito (simula servicio inestable)
2. Función que siempre falla (para ver max_retries)
3. Función que falla con excepción no cubierta (ConnectionError vs ValueError)

10 TESTS:
1. Función que siempre funciona: 0 retries
2. Función que falla 2 veces: éxito al 3er intento
3. Función que siempre falla: lanza excepción tras max_retries
4. Solo captura excepciones especificadas
5. max_retries=0: no reintenta
6. Delay exponencial correcto (sin jitter): 1, 2, 4, 8...
7. max_delay respetado (cap del delay)
8. functools.wraps preserva __name__ y __doc__
9. Jitter añade variación al delay (no exactamente base*2^n)
10. retry_with_stats registra estadísticas correctas

Docstrings Google Style, type hints. Solo librería estándar.
Nota: para tests, usar base_delay=0.01 para que sean rápidos.
```
