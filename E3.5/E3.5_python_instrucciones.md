# E3.5 — Cadena de Prompts: Sistema de Biblioteca en 5 Pasos

## Contexto

Curso "IA Generativa para el Desarrollo: Herramientas". Agentes de IA generan el código completo.

---

## Ficha

| Campo | Valor |
|---|---|
| Código | E3.5-Python |
| Título | Sistema de Biblioteca construido con 5 Prompts Encadenados |
| Módulo | 3.2.4 — Cadena de prompts |
| Duración | 30 minutos |
| Dependencias | Solo librería estándar (json, datetime, dataclasses) |

---

## Objetivo Didáctico

Demostrar **cadena de prompts**: dividir un sistema complejo en 5 prompts secuenciales donde cada uno construye sobre el anterior. Cada prompt genera un módulo independiente y testeado.

**Mensaje clave**: "Para sistemas complejos, divide en prompts pequeños y enfocados. Cada prompt produce un módulo que se integra con los anteriores."

---

## Los 5 Prompts Encadenados

```
PROMPT 1/5 — Modelo de datos:
"Crea las dataclasses Book, Member y Loan para un sistema de
biblioteca. Book tiene isbn, title, author, year, available.
Member tiene id, name, email, active. Loan tiene id, book_isbn,
member_id, loan_date, return_date, returned."

PROMPT 2/5 — Repositorio (usa el output del prompt 1):
"Usando las dataclasses Book, Member y Loan del módulo anterior,
crea clase Library con: add_book, add_member, find_book(query),
find_member(query), get_available_books, get_all_books, get_all_members."

PROMPT 3/5 — Lógica de préstamos (usa outputs 1+2):
"Usando Library del módulo anterior, añade métodos:
loan_book(isbn, member_id) → Loan (marca book como no disponible),
return_book(loan_id) → bool (marca como devuelto y libro disponible),
get_active_loans() → list, get_member_loans(member_id) → list,
get_overdue_loans(days=14) → list."

PROMPT 4/5 — Estadísticas (usa outputs 1+2+3):
"Añade método get_stats() que devuelve dict con:
total_books, available_books, total_members, active_loans,
overdue_loans, most_loaned_books (top 3), most_active_members (top 3)."

PROMPT 5/5 — CLI + Demo (integra todo):
"Crea una demo que muestre el sistema completo:
- Añadir 8 libros, 4 miembros
- Realizar 5 préstamos, devolver 2
- Mostrar estadísticas
- Buscar libro por título
- 10 tests que verifiquen toda la cadena"
```
