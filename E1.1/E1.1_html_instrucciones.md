**Construir un editor Markdown single-page que muestre vista previa HTML en tiempo real mientras el usuario escribe.**

---

## Prompt para el Agente de IA

```
Crea un editor Markdown en un único archivo HTML que incluya:

1. LAYOUT: dos paneles lado a lado (50/50). Izquierda: textarea para
   escribir Markdown. Derecha: vista previa HTML renderizada en tiempo real.
2. TOOLBAR: barra superior con botones para insertar sintaxis Markdown:
   Negrita, Cursiva, Heading (H1-H3), Link, Imagen, Lista, Código inline,
   Bloque de código, Cita, Línea horizontal, Tabla
3. FUNCIONALIDAD:
   - Vista previa se actualiza en tiempo real al escribir (evento input)
   - Los botones insertan la sintaxis en la posición del cursor
   - Contador de palabras y caracteres en la barra inferior
   - Botón "Copiar HTML" que copia el HTML generado al clipboard
   - Botón "Descargar .md" que descarga el contenido como archivo .md
   - Botón "Descargar .html" que descarga la vista previa como HTML
4. ESTILO:
   - Diseño moderno y limpio con CSS Grid o Flexbox
   - Tema oscuro para el editor, tema claro para la vista previa
   - Sintaxis coloreada básica en la vista previa (headings, code, links)
   - Responsive: en móvil los paneles se apilan verticalmente
5. TEXTO INICIAL: cargar con un ejemplo de Markdown que muestre todas
   las funcionalidades (headings, listas, código, tabla, links, imágenes)
6. LIBRERÍA: usar marked.js vía CDN para parsear Markdown a HTML
7. TODO en un único archivo .html (HTML + CSS + JS embebido)
```

## Especificación Técnica

### Archivo: `e1_1_markdown_editor.html`

### Estructura HTML:
- `<header>` con título y toolbar de botones
- `<main>` con dos paneles (CSS Grid: `grid-template-columns: 1fr 1fr`)
- `<textarea id="editor">` para escribir
- `<div id="preview">` para la vista previa renderizada
- `<footer>` con contador de palabras/caracteres y botones de acción

### Botones toolbar (insertan en posición del cursor):
| Botón | Inserta |
|---|---|
| **B** | `**texto**` |
| *I* | `*texto*` |
| H1 | `# ` al inicio de línea |
| H2 | `## ` |
| H3 | `### ` |
| Link | `[texto](url)` |
| Imagen | `![alt](url)` |
| Lista | `- item` |
| Código | `` `código` `` |
| Bloque | ```` ```\ncódigo\n``` ```` |
| Cita | `> cita` |
| Tabla | Tabla 3x3 template |

### JavaScript:
- `marked.parse()` para convertir MD → HTML
- `editor.addEventListener('input', updatePreview)` para tiempo real
- `insertAtCursor(text)`: inserta texto en posición del cursor del textarea
- `copyHTML()`: clipboard API
- `downloadFile(content, filename)`: crea blob + link temporal
- Contador: split por espacios para palabras, .length para caracteres

### CDN:
```html
<script src="https://cdn.jsdelivr.net/npm/marked/marked.min.js"></script>
```

### Texto inicial de ejemplo:
Markdown que demuestre: H1, H2, H3, párrafo, **negrita**, *cursiva*, lista numerada, lista con viñetas, `código inline`, bloque de código con syntax, [link], tabla 3x3, > cita, --- línea horizontal.
