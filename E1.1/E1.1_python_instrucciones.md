# E1.1 — Generación de Texto: Mi Primer Prompt

## Contexto del Curso

Curso **"IA Generativa para el Desarrollo: Herramientas"** (16h, nivel avanzado). Los programadores usan **agentes de IA** (Claude, Copilot Agente, Claude Code) para construir aplicaciones.

**Principio**: La IA es la HERRAMIENTA, las apps Python son el PRODUCTO. Cero API keys en el código.

**Las 3 herramientas funcionan como agentes**: se les da un prompt y generan el código completo.
- **Claude** (claude.ai): prompt en chat → código completo
- **Copilot Agente** (VS Code): prompt en Copilot Chat modo agente → genera archivos en el proyecto
- **Claude Code** (terminal): lee este .md → genera el proyecto

## Objetivo Didáctico

Que el alumno comprenda cómo un agente de IA produce código Python funcional a partir de un prompt en lenguaje natural. Se da el **mismo prompt** a Claude, Copilot Agente y/o Claude Code, se comparan los resultados y se evalúa la calidad.

---

## Tarea de Desarrollo Real

**Construir una función Python que genere resúmenes extractivos de textos largos.**

---

## Prompt para el Agente de IA

> Este es el prompt que se usa con cualquiera de las 3 herramientas (Claude, Copilot Agente, Claude Code):

```
Escribe una función Python llamada generar_resumen que reciba un texto
largo (string) y devuelva un resumen de 3 líneas.

Requisitos:
- Incluye docstring completo con descripción, Args, Returns y Raises
- Usa type hints en la firma y en las variables internas
- Implementa manejo de errores (texto vacío, tipo incorrecto)
- El algoritmo debe ser extractivo: seleccionar las oraciones más
  relevantes basándose en frecuencia de palabras
- Incluye un bloque if __name__ con demo y tests básicos
- Usa solo la librería estándar de Python (re, collections)
- Filtra palabras vacías en español
- Incluye funciones auxiliares privadas para separar responsabilidades
- 7 tests con assert: resumen no vacío, num oraciones correcto,
  texto corto, texto vacío, num_lineas inválido, tipo incorrecto,
  trazabilidad al original
```

---

## Especificación Técnica Detallada

### Archivo: `e1_1_generar_resumen.py`

### Función principal: `generar_resumen(texto: str, num_lineas: int = 3) -> str`
- Validación: TypeError si no es str, ValueError si vacío o num_lineas < 1
- Si hay menos oraciones que las solicitadas, devolver todo el texto
- Algoritmo: dividir en oraciones → calcular frecuencia → puntuar oraciones → seleccionar mejores manteniendo orden original

### Funciones auxiliares:
- `_dividir_en_oraciones(texto: str) -> list[str]`: divide por `.!?` + espacio con regex
- `_normalizar_palabras(texto: str) -> list[str]`: minúsculas, filtra stopwords español, descarta ≤2 chars
- `_calcular_frecuencias(texto: str) -> dict[str, int]`: Counter sobre palabras normalizadas

### Stopwords español (hardcodeadas):
```
el, la, los, las, un, una, unos, unas, de, del, al, a, en, y, o, que, es,
se, no, por, con, para, su, sus, como, más, pero, lo, le, ya, son, este, ha,
muy, también, fue, ser, tiene, esto, entre
```

### Demo (`if __name__`):
- Texto sobre IA Generativa (~1000 caracteres)
- Resumen de 3 líneas + resumen de 1 línea
- **7 tests con assert** (ver prompt arriba)

## Comparativa entre Agentes

| Aspecto | Claude (chat) | Copilot Agente (VS Code) | Claude Code (terminal) |
|---|---|---|---|
| Input | Prompt en chat web | Prompt en Copilot Chat | Lee este .md |
| Output | Código en el chat, copiar manualmente | Crea/edita archivos directamente en el proyecto | Crea archivos directamente |
| Iteración | "Mejora X" en el mismo chat | "Mejora X" en Copilot Chat | Instrucciones en terminal |
| Contexto | Solo lo que le pegas | Todo el proyecto abierto en VS Code | Todo el directorio del proyecto |

- ¿Alguno olvidó los tests? ¿Los docstrings? ¿El manejo de errores?
- ¿Cuál fue más fácil de iterar cuando algo no estaba bien?
