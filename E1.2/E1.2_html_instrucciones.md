## Especificación Técnica

### Archivo: `e1_2_token_visualizer.html`

### Tokenizador por palabras (JS):
```javascript
function tokenizarPalabras(texto) {
    return texto.match(/\w+|[^\w\s]/g) || [];
}
```

### Tokenizador por caracteres:
```javascript
function tokenizarCaracteres(texto) {
    return texto.split('');
}
```

### BPE simulado (JS):
Mismo algoritmo que la versión Python pero en JS:
1. Cada palabra → array de chars + `</w>`
2. Loop: contar pares adyacentes, fusionar el más frecuente
3. Registrar historial de merges

### Gráfico de barras CSS:
```css
.bar { height: 24px; background: var(--color); transition: width 0.3s; }
```
Width proporcional al número de tokens.

### Actualización en tiempo real:
```javascript
editor.addEventListener('input', () => {
    actualizarPalabras();
    actualizarCaracteres();
    actualizarBPE();
    actualizarEstadisticas();
});
```

## Resultado Esperado

Al abrir en navegador:
- Textarea con texto de ejemplo
- 3 paneles con tokens coloreados (cada método con colores distintos)
- Panel BPE con tabla de merges y botón paso a paso
- Estadísticas actualizándose en tiempo real al escribir
- Barras comparativas mostrando que Palabras < BPE < Caracteres en número de tokens
