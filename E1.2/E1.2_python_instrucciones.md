## Prompt para el Agente de IA

```
Escribe un script Python educativo que demuestre cómo funcionan los
tokens y los embeddings en los LLMs. El script debe tener 3 partes:

PARTE 1 - Tokenización (3 métodos + comparativa):
- tokenizar_por_palabras: divide por palabras y puntuación con regex
- tokenizar_por_caracteres: cada carácter es un token
- tokenizar_bpe_simulado: simulación paso a paso de Byte Pair Encoding
  que muestre cada fusión (merge) con par, nuevo token y frecuencia.
  Debe usar marcador </w> al final de cada palabra.
- comparar_metodos: ejecuta los 3 sobre el mismo texto

PARTE 2 - Embeddings y similitud:
- calcular_similitud: usa TF-IDF de scikit-learn con bigramas,
  calcula similitud coseno entre todos los pares, extrae top 5
  palabras representativas por frase

PARTE 3 - Visualización:
- visualizar_embeddings_2d: reduce a 2D con TruncatedSVD

Usa estas 6 frases de demo para embeddings:
  [0] "Python es un lenguaje de programación muy popular"
  [1] "Python es uno de los lenguajes más usados en el mundo"
  [2] "Me gusta programar en Python y JavaScript"
  [3] "El clima de Madrid es cálido en verano"
  [4] "La temperatura en verano en Madrid es alta"
  [5] "Los gatos son animales domésticos independientes"

Requisitos: docstrings Google Style, type hints, manejo de errores,
12 tests con assert. Solo scikit-learn y numpy como dependencias.
NO uses tiktoken ni sentence-transformers.
```

---

## Especificación Técnica Detallada

### Archivo: `e1_2_tokens_embeddings.py`

### PARTE 1: Tokenización

**`tokenizar_por_palabras(texto: str) -> dict`**: regex `\w+|[^\w\s]`, vocabulario con IDs únicos. ValueError si vacío.

**`tokenizar_por_caracteres(texto: str) -> dict`**: cada char es token. Mismo formato de salida.

**`tokenizar_bpe_simulado(texto: str, num_merges: int = 10) -> dict`**:
1. Cada palabra → lista de caracteres + `</w>`
2. Loop: contar pares adyacentes (Counter), fusionar el más frecuente
3. Historial: paso, par_fusionado, nuevo_token, frecuencia
4. ValueError si vacío o num_merges < 1

**`comparar_metodos(texto: str, num_merges: int = 15) -> list[dict]`**: los 3 métodos, devuelve resumen.

### PARTE 2: Embeddings

**`calcular_similitud(frases: list[str]) -> dict`**: TfidfVectorizer con ngram_range=(1,2), cosine_similarity, top 5 palabras por frase. ValueError si < 2 frases.

### PARTE 3: Visualización

**`visualizar_embeddings_2d(frases: list[str]) -> dict`**: TF-IDF + TruncatedSVD(n_components=2, random_state=42).

### 12 tests:
1. Palabras: `["Hola", "mundo"]`, 2 tokens
2. Puntuación separada
3. Caracteres: `"ABC"` → 3, vocab=3
4. BPE fusiona par más frecuente
5. Más merges = menos tokens
6. ValueError vacío ×3
7. Comparativa devuelve 3 métodos
8. Idénticas → similitud 1.0
9. Relacionadas > no-relacionadas
10. ValueError < 2 frases
11. Visualización 2D: 3 puntos con x, y
12. Top palabras no vacío

## Resultado Esperado

- BPE muestra "programación" construida paso a paso desde caracteres
- Comparativa: Palabras (13 tokens), Caracteres (90), BPE (60) → BPE es el equilibrio
- Matriz similitud: [3]↔[4] (clima) y [0]↔[1] (Python) más similares, [5] (gatos) aislado
- 12/12 tests PASS
