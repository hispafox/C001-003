# E2.3 HTML/JS — Quiz Interactivo "¿Es Real esta API?"

## Contexto

Curso "IA Generativa para el Desarrollo: Herramientas". Agentes de IA generan el código completo.

---

## Ficha

| Campo | Valor |
|---|---|
| Código | E2.3-HTML |
| Título | Quiz "¿Es Real esta API?" |
| Módulo | 2.2.1 — Inconsistencia y alucinaciones |
| Dependencias | Archivo único .html, highlight.js por CDN (syntax highlighting) |

---

## Objetivo Didáctico

Gamificar el pensamiento crítico: el alumno evalúa 10 snippets de código y decide si la API usada es real o inventada. Entrena el ojo para detectar alucinaciones de la IA.

---

## Prompt para el Agente de IA

```
Crea un quiz interactivo en un único archivo HTML donde el usuario
evalúa si snippets de código Python usan APIs reales o inventadas.

10 PREGUNTAS (5 reales + 5 inventadas, en orden aleatorio cada vez):

REALES:
1. from collections import defaultdict
   → defaultdict(list) para agrupar datos
2. from pathlib import Path
   → Path("archivo.txt").read_text()
3. import json
   → json.dumps(data, indent=2, ensure_ascii=False)
4. from itertools import groupby
   → groupby(sorted(data), key=lambda x: x["tipo"])
5. from functools import lru_cache
   → @lru_cache(maxsize=128) sobre una función recursiva

INVENTADAS (parecen reales pero NO existen):
6. from pandas import QuickFrame
   → QuickFrame.from_dict(data).auto_clean()
7. from sklearn.neural import DeepClassifier
   → DeepClassifier(layers=[64, 32]).fit(X, y)
8. from collections import SortedDict
   → SortedDict(key=lambda x: x.priority)
9. import fastvalidate
   → fastvalidate.check_schema(data, rules)
10. from pathlib import RemotePath
    → RemotePath("s3://bucket/file.csv").download()

INTERFAZ:
- Mostrar un snippet de código con syntax highlighting (highlight.js CDN)
- Dos botones grandes: "✅ API Real" y "❌ API Inventada"
- Al responder:
  - Si acierta: fondo verde, explicación de por qué es real/inventada
  - Si falla: fondo rojo, explicación detallada
  - Mostrar la documentación oficial (link) si es real, o explicar qué
    sería la alternativa real si es inventada
- Barra de progreso: pregunta X de 10
- Puntuación en tiempo real: aciertos / total
- Al finalizar las 10:
  - Resultado con nota (10/10 = "Experto", 7-9 = "Buen ojo",
    4-6 = "Necesitas práctica", 0-3 = "Cuidado con las alucinaciones")
  - Resumen de errores con explicación
  - Botón "Jugar de nuevo" (reordena las preguntas)
  - Estadísticas: racha actual, mejor racha

ESTILO:
- Tema oscuro, código con syntax highlighting
- Botones grandes y claros (verde para Real, rojo para Inventada)
- Animaciones de transición entre preguntas
- Barra de progreso visual
- Confetti o animación si se aciertan todas (CSS only, sin librería)
- Responsive

CDN: highlight.js para syntax highlighting del código Python
```

## Especificación Técnica

### Archivo: `e2_3_api_quiz.html`

### Estructura de datos de preguntas:
```javascript
var QUESTIONS = [
    {
        code: "from collections import defaultdict\n\ndata = [('a', 1), ('b', 2), ('a', 3)]\ngrouped = defaultdict(list)\nfor key, val in data:\n    grouped[key].append(val)",
        isReal: true,
        explanation: "defaultdict es una clase real del módulo collections de la librería estándar de Python.",
        alternative: null,
        docLink: "https://docs.python.org/3/library/collections.html#collections.defaultdict"
    },
    // ...
];
```

### Highlight.js CDN:
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/highlightjs/cdn-release@11.9.0/build/styles/atom-one-dark.min.css">

```

### Aleatorización:
```javascript
function shuffle(array) {
    for (var i = array.length - 1; i > 0; i--) {
        var j = Math.floor(Math.random() * (i + 1));
        var temp = array[i]; array[i] = array[j]; array[j] = temp;
    }
    return array;
}
```

### Confetti CSS (si 10/10):
Usar `@keyframes` con partículas absolutas generadas con JS y animadas con CSS.
