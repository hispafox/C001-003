## Objetivo Didáctico

Dar el **MISMO prompt** a los 3 agentes (Claude, Copilot Agente, ChatGPT) y comparar qué genera cada uno. El gestor de contraseñas es ideal porque requiere seguridad, UX de terminal y diseño de datos — áreas donde cada LLM puede tomar decisiones diferentes.

**Este es el ejercicio comparativo clave del Módulo 2.**

---

## Prompt para el Agente de IA

```
Crea un gestor de contraseñas CLI en Python. Requisitos:

GENERACIÓN DE CONTRASEÑAS:
- generate(length=16, uppercase=True, lowercase=True,
           digits=True, symbols=True) -> str
- Usar módulo secrets (no random) para seguridad criptográfica
- Garantizar al menos 1 carácter de cada tipo seleccionado
- Calcular y mostrar "fortaleza" (débil/media/fuerte/muy fuerte)
  basada en longitud + variedad de tipos

ALMACENAMIENTO:
- Guardar en archivo JSON: {"entries": [{"service", "username",
  "password_b64", "created_at", "notes"}]}
- Contraseñas codificadas en base64 (NO encriptación real —
  es educativo, no producción)
- Archivo por defecto: passwords.json en directorio actual

CLASE PasswordManager:
- __init__(self, filepath="passwords.json")
- generate_password(length, **options) -> str
- evaluate_strength(password) -> dict con score, level, feedback
- add_entry(service, username, password, notes="") -> dict
- get_entry(service) -> dict | None
- list_entries() -> list[dict] (sin mostrar contraseñas)
- search(query) -> list[dict] (búsqueda parcial en service/username)
- delete_entry(service) -> bool
- export_csv(filepath) -> int (número de entries exportadas)

CLI con argparse y subcomandos:
- generate: genera contraseña con opciones de longitud y tipos
- add: añade entrada (pide password con getpass si no se proporciona)
- get: muestra entrada por servicio
- list: lista todas las entradas
- search: busca por texto
- delete: elimina entrada
- export: exporta a CSV

Sin argumentos: demo interactiva + 10 tests.
Docstrings Google Style, type hints. Solo librería estándar.
```

## Comparativa entre Agentes

| Aspecto | Claude | Copilot Agente | ChatGPT |
|---|---|---|---|
| Seguridad | ¿Usa secrets? ¿base64? | ¿Mismas decisiones? | ¿O usa random? |
| CLI | ¿Subcomandos con argparse? | ¿Diferente estructura? | ¿Click? |
| Fortaleza | ¿Cómo evalúa? | ¿Mismos criterios? | ¿Más/menos estricto? |
| Tests | ¿Los 10 tests? | ¿Genera tests? | ¿Cuántos? |
| Extras | ¿Añade algo no pedido? | ¿Funciones extra? | ¿Algo diferente? |
