## Tarea de Desarrollo Real

**Construir un formulario web interactivo que evalúe el nivel de riesgo de un sistema de IA según el AI Act europeo, con visualización de resultados.**

---

## Prompt para el Agente de IA

```
Crea un evaluador interactivo de riesgo del AI Act europeo en un único
archivo HTML. Requisitos:

1. FORMULARIO de evaluación con preguntas de selección múltiple:
   
   Pregunta 1: "¿Qué tipo de datos procesa el sistema?"
   Opciones: Datos públicos, Datos personales, Datos biométricos,
             Datos sensibles (salud, orientación, etnia)
   
   Pregunta 2: "¿En qué sector se aplica?"
   Opciones: Entretenimiento/ocio, Productividad/oficina,
             Educación, Empleo/RRHH, Salud/seguros, Justicia/seguridad,
             Infraestructura crítica
   
   Pregunta 3: "¿Qué nivel de autonomía tiene en la toma de decisiones?"
   Opciones: Asistencia (humano decide), Recomendación (humano valida),
             Semiautónomo (humano supervisa), Autónomo (sin supervisión)
   
   Pregunta 4: "¿Afecta a derechos fundamentales de las personas?"
   Opciones: No, Indirectamente, Directamente, Acceso a servicios esenciales
   
   Pregunta 5: "¿Incluye identificación biométrica?"
   Opciones: No, Verificación (1:1), Identificación (1:N),
             Vigilancia masiva en tiempo real
   
   Pregunta 6: "Describe brevemente tu sistema de IA" (textarea libre)

2. SISTEMA DE SCORING:
   Cada respuesta suma puntos a los niveles de riesgo:
   - Datos sensibles/biométricos → +puntos a alto/inaceptable
   - Sector justicia/infraestructura → +puntos a alto
   - Autonomía sin supervisión → +puntos a alto
   - Vigilancia masiva → directo a inaceptable
   - El textarea se analiza por keywords (mismo sistema que E1.4 Python)
   
3. RESULTADO:
   - Panel grande con el nivel de riesgo: color + icono + nombre
     (🚫 INACEPTABLE=rojo, ⚠️ ALTO=naranja, ℹ️ LIMITADO=amarillo, ✅ MÍNIMO=verde)
   - Barra de progreso visual mostrando la puntuación
   - Gráfico radar (Chart.js) con puntuación en cada dimensión:
     Datos, Sector, Autonomía, Derechos, Biometría
   - Justificación textual basada en las respuestas
   - Lista de obligaciones según el nivel (qué debe cumplir el sistema)
   
4. OBLIGACIONES POR NIVEL (mostrar tras evaluación):
   - Inaceptable: "Este sistema está PROHIBIDO en la UE"
   - Alto: conformidad, registro, transparencia, supervisión humana,
     evaluación de impacto, documentación técnica
   - Limitado: informar al usuario que interactúa con IA,
     etiquetar contenido generado
   - Mínimo: sin obligaciones específicas, código de conducta voluntario

5. BOTONES: "Evaluar", "Reiniciar", "Descargar informe" (genera PDF-like
   en nueva pestaña con window.print())

6. DATOS INICIALES: formulario vacío pero con placeholder descriptivo
   en el textarea

7. ESTILO: diseño profesional, colores institucionales (azul/blanco),
   transiciones suaves al mostrar resultado. Responsive.

8. LIBRERÍA: Chart.js por CDN solo para el gráfico radar.

9. TODO en un único archivo .html.
```

## Especificación Técnica

### Archivo: `e1_4_ai_act_evaluator.html`

### Sistema de scoring (JS):
```javascript
const PESOS = {
    datos: { publicos: 0, personales: 1, biometricos: 3, sensibles: 4 },
    sector: { entretenimiento: 0, productividad: 0, educacion: 2,
              empleo: 3, salud: 3, justicia: 4, infraestructura: 4 },
    autonomia: { asistencia: 0, recomendacion: 1, semiautonomo: 2, autonomo: 4 },
    derechos: { no: 0, indirectamente: 1, directamente: 3, servicios: 4 },
    biometria: { no: 0, verificacion: 1, identificacion: 3, vigilancia: 5 },
};
```

Nivel = función de la suma total:
- ≥15 o vigilancia masiva → inaceptable
- ≥8 → alto
- ≥4 → limitado
- <4 → mínimo

### Chart.js radar:
```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```
5 ejes: Datos, Sector, Autonomía, Derechos, Biometría. Valores 0-5.

### Obligaciones (mostrar dinámicamente según nivel):
Objeto con arrays de strings por nivel.

## Resultado Esperado

Al abrir en navegador:
- Formulario profesional con 5 preguntas + textarea
- Al pulsar "Evaluar": resultado con color, icono, gráfico radar
- Obligaciones listadas según el nivel determinado
- "Descargar informe" abre versión imprimible
- "Reiniciar" limpia todo
