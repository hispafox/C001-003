   título, descripción y select de prioridad. Botón "Añadir tarea"
5. FILTROS: barra de filtro por prioridad (Todas, Alta, Media, Baja)
   que muestra/oculta tarjetas según la selección

8. DATOS INICIALES: 6 tarjetas de ejemplo distribuidas en las 3 columnas
   (2 por columna) con prioridades variadas, sobre temas de desarrollo
   de software

   tarjetas blancas con sombra, badges de prioridad con color.

    Usar solo HTML5 Drag and Drop API nativo, NO librerías.

## Especificación Técnica

### Archivo: `e1_3_kanban_board.html`

### HTML5 Drag and Drop:
```javascript
// En cada tarjeta:
tarjeta.draggable = true;
tarjeta.addEventListener('dragstart', handleDragStart);
tarjeta.addEventListener('dragend', handleDragEnd);

// En cada columna:
columna.addEventListener('dragover', handleDragOver);  // e.preventDefault()
columna.addEventListener('drop', handleDrop);
columna.addEventListener('dragenter', handleDragEnter);
columna.addEventListener('dragleave', handleDragLeave);
```

### Estructura de datos:
```javascript
const tareas = [
    { id: 1, titulo: "Diseñar API REST", descripcion: "Definir endpoints...",
      prioridad: "alta", columna: "todo", fecha: "2026-03-08" },
    // ...
];
```

### localStorage:
```javascript
function guardar() { localStorage.setItem('kanban-data', JSON.stringify(tareas)); }
function cargar() { return JSON.parse(localStorage.getItem('kanban-data') || '[]'); }
```

### Título editable:
```javascript
titulo.addEventListener('dblclick', () => {
    titulo.contentEditable = true;
    titulo.focus();
});
titulo.addEventListener('blur', () => {
    titulo.contentEditable = false;
    guardar();
});
```

## Resultado Esperado

Al abrir en navegador:
- 3 columnas con 2 tarjetas cada una (datos iniciales)
- Arrastrar tarjetas entre columnas funciona con feedback visual
- Formulario para añadir nuevas tareas
- Filtro por prioridad funcional
- Contadores por columna se actualizan
- Recargar la página mantiene el estado (localStorage)
- Doble clic en título permite editar
