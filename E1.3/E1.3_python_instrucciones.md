## Objetivo Didáctico

Demostrar que un agente de IA puede generar una **aplicación CLI completa y funcional** de principio a fin. Se da el mismo prompt a los tres agentes y se compara: ¿cuál genera la app más completa al primer intento?

**Mensaje clave**: "Lo que antes costaba 2 horas, un agente de IA lo genera en 30 segundos. Pero SIEMPRE hay que revisar y testear."

---

## Tarea de Desarrollo Real

**Construir una aplicación CLI que organice archivos de un directorio por tipo.**

---

## Prompt para el Agente de IA

```
Crea una aplicación CLI Python llamada file_organizer que organice
archivos de un directorio por tipo. Requisitos:

1. Clasificar archivos por extensión en carpetas: images/, documents/,
   code/, data/, media/, archives/, fonts/, other/
2. Argumento posicional: directorio a organizar
3. Opción --dry-run que simule sin mover nada
4. Opción --verbose para más detalle
5. Logging a archivo (.file_organizer.log) y consola
6. Resolución de conflictos de nombres (foto.jpg → foto_1.jpg)
7. Ignorar archivos ocultos (empiezan por .)
8. Informe resumen al finalizar con desglose por categoría
9. Manejo de errores robusto (directorio inexistente, permisos)
10. Clase FileOrganizer con métodos: clasificar_archivo,
    resolver_conflicto, organizar, generar_informe
11. Si se ejecuta sin argumentos CLI: demo + 10 tests automáticos
    usando tempfile (directorio temporal con archivos de prueba)
12. Clasificación case-insensitive (.JPG = .jpg)

Usa solo librería estándar. Incluye docstrings Google Style y type hints.
```

## Especificación Técnica Detallada

### Archivo: `e1_3_file_organizer.py`

### Categorías:
```python
CATEGORIAS = {
    "images": {".jpg", ".jpeg", ".png", ".gif", ".bmp", ".svg", ".webp", ".ico", ".tiff"},
    "documents": {".pdf", ".doc", ".docx", ".xls", ".xlsx", ".ppt", ".pptx", ".odt", ".txt", ".rtf"},
    "code": {".py", ".js", ".ts", ".html", ".css", ".java", ".c", ".cpp", ".h", ".rb", ".go", ".rs", ".php", ".sql", ".sh", ".bat"},
    "data": {".csv", ".json", ".xml", ".yaml", ".yml", ".toml", ".ini", ".cfg", ".env", ".db", ".sqlite"},
    "media": {".mp3", ".wav", ".flac", ".mp4", ".avi", ".mkv", ".mov", ".wmv", ".ogg", ".m4a"},
    "archives": {".zip", ".tar", ".gz", ".rar", ".7z", ".bz2", ".xz"},
    "fonts": {".ttf", ".otf", ".woff", ".woff2", ".eot"},
}
```

### Clase `FileOrganizer`:
- **`__init__(directorio, dry_run=False)`**: valida que existe, configura logging
- **`clasificar_archivo(archivo) -> str`**: extensión → categoría (case-insensitive)
- **`resolver_conflicto(destino) -> Path`**: sufijo numérico incremental
- **`organizar() -> dict`**: escanea (no recursivo), ignora ocultos, mueve o simula
- **`generar_informe() -> str`**: resumen legible

### CLI: argparse con `directorio`, `--dry-run`, `--verbose`, `--version`

### Modo dual: con args → CLI real / sin args → demo + tests

### 10 tests (con tempfile):
1. Clasificación extensiones (.jpg→images, .py→code, .csv→data)
2. Case-insensitive (.JPG→images)
3. Desconocida (.xyz→other)
4. Dry-run no mueve archivos
5. Dry-run registra operaciones
6. Ejecución real mueve archivos
7. Se crean carpetas correctas
8. Ocultos se ignoran
9. Resolución de conflictos (duplicados)
10. Directorio inexistente → ValueError
